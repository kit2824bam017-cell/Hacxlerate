# LearnAI Assessment & Mock Test Roadmap

## Goals
Expand LearnAI to support both interactive **Curriculum Quizzes** (formative, Socratic-guided practice) and full **Mock Tests** (summative, timed exam simulation with question palette, exam environment, and comprehensive diagnostic scorecard).

## Milestones
- [x] **Milestone 1**: System Architecture & Specification
- [ ] **Milestone 2**: Backend & Database Model Extensions (`quiz_type`, `duration_minutes`, `total_marks`, Mock Test endpoints)
- [ ] **Milestone 3**: Teacher Mock Test Management (`TeacherMockTests.jsx`)
- [ ] **Milestone 4**: Student Timed Mock Test Interface (`StudentMockTestHub.jsx`)
- [ ] **Milestone 5**: Navigation & Aesthetic Polish across Student & Teacher Dashboards
- [ ] **Milestone 6**: Verification & End-to-End Testing
